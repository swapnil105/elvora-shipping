# ELVORA SHIPPING · إلفورا للشحن

> Global Freight Forwarding & Maritime Logistics · Dubai, United Arab Emirates

An interactive web platform showcasing ELVORA's international maritime presence, global trade routes, dynamic shipping journeys, logistics services, and interactive global port connectivity network.

---

## 🌟 Key Features

- **Dynamic Interactive Global Network Map**: Visualizes shipping routes and trade corridors connecting Dubai (Jebel Ali) with East Asia, Europe, Mediterranean, North America, and South America.
- **Vessel Fleet & Interactive Journey**: Real-time cargo journey stages with interactive timeline, inspection checkpoints, and documentation trackers.
- **Full Freight Suite**: Ocean FCL/LCL, Air Express, Customs Clearance, Cold Chain Logistics, and Port-to-Door Multimodal solutions.
- **Bilingual Design**: English & Arabic typography with curated maritime color palette.
- **Instant Quote Calculator**: Interactive volumetric & freight route calculator.
- **Custom Vector Branding & Favicon**: Crisp multi-resolution vector branding and PWA webmanifest.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4
- **Build Tool**: Vite 8
- **Icons & Graphics**: SVG Vector Illustrations & Canvas Interactive Visualizer

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/swapnil105/elvora-shipping.git

# Navigate to project directory
cd elvora-shipping

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production

```bash
npm run build
```
