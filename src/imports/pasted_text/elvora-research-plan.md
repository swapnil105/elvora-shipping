# PHASE 2 — CREATE 5 COMPLETELY DIFFERENT ELVORA CONCEPTS

After research, create **5 radically different creative directions** for ELVORA.

For example:

## CONCEPT 01 — "THE GLOBAL CURRENT"

A cinematic ocean / shipping route experience.

The user enters a global maritime environment.

Shipping routes, ports, cargo and movement become part of the interface.

Dubai becomes the strategic gateway between East and West.

The website feels like:

**Bloomberg + premium maritime + cinematic WebGL**

---

## CONCEPT 02 — "DUBAI GATEWAY"

Dubai is treated as the central visual metaphor.

The experience begins around Dubai's skyline / coastline / port environment.

As the user scrolls, the world expands outward from Dubai into global trade routes.

The visual story:

**Dubai → Gulf → Asia → Europe → Africa → Global**

# TECHNICAL DIRECTION

Assume we are building a modern custom website.

Potential stack:

* React
* Vite / Next.js where appropriate
* Three.js / React Three Fiber if justified
* GSAP
* Lenis or equivalent smooth scrolling where appropriate
* CSS
* WebGL

But technology is NOT the objective.

The experience is the objective.

If a visual effect can be achieved better with CSS than WebGL, use CSS.

If 3D adds no meaningful value, don't use it.

---

# PERFORMANCE REQUIREMENT

This is critical.

I want:

**Premium visual experience + excellent performance.**

Target:

* Fast initial load
* Excellent Lighthouse performance
* Optimized images/video
* Lazy-loaded 3D
* Mobile-specific rendering strategy
* Reduced-motion support
* No unnecessary JavaScript
* No enormous 3D assets
* No blocking animations
* No animation that destroys usability

Desktop and mobile should NOT simply be the same experience scaled down.

Design a deliberate mobile experience.

Cinematic route animation / simplified map / touch interaction

Desktop:
Complex mouse interaction

Mobile:
Touch / scroll interaction

The mobile experience must feel intentional rather than compromised.
